# v0.8.105 侵入口チェックと壁の突破（端末を壁で囲む裏技対策）
- 開始前: 端末の攻撃範囲(水平2マス)から半径16の外周まで、敵が歩ける通路(足元固体・足と頭が空き・1段昇降)が1本も無いと「侵入口がありません」で開始不可。
- 戦闘中: 3秒ごとに通路を検査。2回連続(6秒)塞がっていたら、最少枚数で外へ抜けるルート上の一番外側の壁を特定し、
  一番近いスクラッパー(いなければジャマー)がその壁の外側へ取り付く。4秒間 火花＋金床音＋端末の警告音 → 足/頭の2マスを破壊。
  取り付いた敵を倒せば「突破を阻止！」。敵が止まっているだけ(通路は開いている)では壊さない。
- 破壊対象: 半径16内の一般ブロック(壁材)のみ。本アドオンの機械、チェスト・樽・シュルカー・ホッパー・かまど類・ベッド等、
  黒曜石・岩盤・バリア等は壊さない。それらで完全に密閉された場合は、入口が開くまでウェーブのクリア判定を保留。
