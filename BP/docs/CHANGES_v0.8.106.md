# v0.8.106 攻城機迎撃（ボス戦）・新ザコ2種・並列加工モジュール

## 攻城機迎撃（防衛端末の別モード）
- 通常防衛(3ウェーブ)を一度クリアすると、ワールド単位で解禁。旧ワールドは「通常防衛で勝利済みの端末」を開くと解禁。
- 2ウェーブ: 第1波 スクラッパー12・ジャマー2・ボルトラット3 / 第2波 攻城機1・スクラッパー8・ジャマー2・修理ドローン2。
- 開始前チェックは通常防衛と共通（侵入口・出現地・近隣端末）＋攻城機用に幅3・高さ3の平地。無ければ理由を表示。
- 端末データに mode を追加（古いデータは normal 扱い）。報酬は通常(軍用制御核2)と攻城機(攻城制御核2＋軍用制御核2)で別管理、受取は先に保留を消すので二重にならない。
- 相打ち(端末耐久0とウェーブ全滅が同時)は敗北。耐久判定をクリア判定より先に。

## 攻城機（orbital_foundry:siege_engine）
- 本体HP 420。正面装甲はダメージ25%、背面50%。左右の冷却器 各HP70（側面からの命中で減る）。
- 冷却器を両方壊すと12秒間 正面装甲が開き（モデルの装甲板が観音開き・炉心が露出）、どの方向からも等倍。12秒後に閉じて冷却器が再起動。
- 端末から水平16以内で、4秒予告の衝撃波（端末-12、ブロックは壊さない）。HP半分以下で間隔14→8秒。
  発射時刻は戦闘データに保存し、毎秒条件(生存・射程・未開放・同じ作戦)を再確認。予告中に撃破/冷却器両破壊で中断、作戦終了で破棄。
- 砲塔の命中は砲口座標、プレイヤーは攻撃者/投射物の位置で 正面/左/右/背面 を判定。
- 演出: 履帯と転輪、排気、砲塔の首振り、衝撃波の充填(エミッター回転・発光・車体が沈む)、冷却器の破裂(水色の飛沫)、装甲開放フラッシュ、撃破時の連鎖爆発。

## 新ザコ
- ボルトラット(gnawer): HP30・高速。装填済みの砲塔へ走り、隣で毎秒3発かじる(顎がガチガチ動く・真鍮の削りかす)。近距離では砲塔の最優先目標。通常防衛の第2・3波にも登場。
- 修理ドローン(mender): HP40・3ローターで浮遊。群れの後ろに付き、4秒ごとに一番傷ついた味方を+10（緑のビーム・十字ランプ点灯）。攻城機の冷却器も回復（開放中は不可）。砲塔の最優先目標。通常防衛の第3波にも登場。

## 並列加工モジュール
- 作業台: 鋼板4・銅線2・処理装置2・攻城制御核1。粉砕機か電気炉にモジュールを持って使うと装着（1台1個）。機械を回収すると戻る。
- 新しく始める加工から 時間60%・1回の電力125%（手動/自動搬入の両方）。加工中の値は変わらない。画面に「並列」表示。
