# v0.8.113 攻城機の見た目・演出の作り直し
- 近接の叩きつけ: 届く範囲を中心から5.4→9.7ブロック(1.8倍)、高さも少し広げた。命中時に砂塵リング・火花・衝撃線・地鳴り(カメラ揺れ)。
- 冷却器の破損を左右で別デザインに: 左=凍結破裂(霜の結晶・えぐれた胴・垂れた配管、冷却液の噴出と冷気)、右=爆発炎上(めくれた装甲片・赤熱した芯、炎と火花)。破損後も毎秒その側から噴出/炎上。
- 弱点露出の専用テクスチャ: 白熱した炉心(照準入り)が脈動、赤い照準ブラケットが点滅しながら前に出る、装甲板の裏(赤い警告帯)と油圧ピストン、車体前面の警告灯と赤黒の帯。開放時に画面タイトル「弱点露出！」、蒸気噴出・閃光・カメラ揺れ。
- 衝撃波: 充填中は射程半径16を地面に赤い点線で表示、エミッターの光柱。発射で3重の衝撃リング・砂塵の輪・螺旋の衝撃線・端末で大爆発・広範囲のカメラ揺れ。専用SE(衝撃波)。
- 走行音: 専用SEを6.5秒(前後0.25秒フェード)に切り出し、6.25秒ごとに重ねてループ。HP半分以下で少し低い音。
- 移動中は履帯の砂煙と火花、HP半分以下で車体から煙と炎。排気は2本の煙突から。
- 衝撃波の端末側の着弾音を専用SE(siege_impact: 砲撃の爆発＋土砂・金属の破片)に変更。攻城機側は従来の衝撃波SE。

- このアドオンの敵・ボス7種(スクラッパー/ジャマー/修理ドローン/ボルトラット/攻城機/地上拠点の警備機/オーバーシア)にスポーンエッグ。クリエイティブのインベントリに出る。
- サバイバル/アドベンチャーで使うとキャンセル(「クリエイティブ専用」)。ディスペンサー等で出た防衛の敵は自動で消す。
- エッグで出した個体は頭上に「[デバッグ]」、作戦・ボス記録と無関係でも再読込時に消されない。防衛の行動パターン(突進・かじり・回復・冷却器/装甲・衝撃波)は作戦中の個体のみ。
