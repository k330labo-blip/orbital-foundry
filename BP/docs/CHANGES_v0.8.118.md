# v0.8.118 攻城機の装甲開放と進行停止の修正
- 装甲扉がゆっくり開かない: 統合版のアニメーションは位置のXがジオメトリと左右逆。開始オフセットが外側(+11.5/-11.5)になっていて、扉は最初から開いた位置付近にあり外へ動くだけだった → 符号を反転し、中央(閉じた位置)から1.6秒かけてレール端へ滑るように。
- 一度止まると再び進まない: 停止イベントで足した movement:0 のグループを外すと、移動速度のコンポーネントごと消えて元の値に戻らない(統合版の仕様) →
  元の速度を持つ mobile グループを用意し、停止=mobile除去→channel追加、再開=channel除去→mobile追加 を順番どおり(sequence)に実行。攻城機・ジャマー・修理ドローン・ボルトラットすべて。
- 保険: 攻城機が装甲閉鎖中・充填していないのに3秒動かなければ移動を戻すイベントを再送、6秒で端末方向へ押し出し。
- 扉をさらにゆっくり: 開くのに3.2秒(1.6→3.2)。閉じるアニメを新設し、開放12秒の最後3.2秒でゆっくり閉まる(エンティティプロパティ closing、アニメ状態 open→closing→closed)。閉まり始めに低い作動音と蒸気。
