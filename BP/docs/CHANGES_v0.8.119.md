# v0.8.119 野菜8種 (畑・種・収穫)
- 作物: トマト・トウモロコシ・枝豆・サツマイモ・キャベツ・タマネギ・パプリカ・イチゴ。耕地に植えて6段階で成長(芽→本葉→株が広がる→花・根→未熟な実→収穫可能)。
- 成長: ランダムティックで進み、明るく湿った耕地での成熟の平均はトマト9分・トウモロコシ12分・枝豆8分・サツマイモ14分・キャベツ10分・タマネギ9分・パプリカ11分・イチゴ7分。乾いた耕地は半分の速さ、明るさ9未満では止まる。骨粉で1〜2段階。耕地が壊れる/土に戻ると株は落ちる(種/苗1個)。
- トウモロコシは後半2段階で2ブロックの高さへ伸び、上が塞がっているとその手前で止まる。
- 収穫: 何度も採れる4種(トマト2〜4・枝豆2〜4・パプリカ1〜3・イチゴ2〜5)は熟した株を右クリック→未熟な実に戻り、約3分(2〜4分)で再び熟す。イチゴは30%で苗も。
  その他は熟した株を壊して: トウモロコシ1〜2本・サツマイモ2〜3個・キャベツ1玉＋種1〜2個・タマネギ2〜4個(＋どれも種/苗1個。サツマイモ・タマネギは収穫物そのものを植える)。
- 種: 背の低い草を刈ると12%で8種のどれか(トマト・枝豆・イチゴは出やすく、パプリカ・サツマイモは少しレア)。トマト・トウモロコシ・枝豆・パプリカは収穫物1個→種2個(作業台)。
- 満腹度/隠し満腹度: トマト6/9.6・トウモロコシ8/12.8・枝豆6/12.0・サツマイモ10/14.0・キャベツ8/11.2・タマネギ7/11.2・パプリカ7/12.6・イチゴ5/8.0。
- 未実装(次段階): 野生株の自然生成、全自動栽培槽、加工品・缶詰機。
