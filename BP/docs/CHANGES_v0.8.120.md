# v0.8.120 野菜の野生株
- 8種の野生株ブロック (orbital_foundry:wild_<作物>)。成熟した姿で、色がくすみ葉がまばら (トマトは支柱なし)。草ブロック・土・ポドゾル等の上に立つ。
- 壊すと食べられる実1〜2個＋植え直し用の種/苗1個 (サツマイモ・タマネギは実そのもの)。
- 地形生成: 1〜3株の小さな群落 (半径2)。チャンクごとに 1/6〜1/8 の確率 (トマト・トウモロコシ・枝豆・イチゴ 1/6、キャベツ・タマネギ 1/7、サツマイモ・パプリカ 1/8)。1群落 1〜4 回の配置、新しく生成される地形のみ。
  トマト=草原・森林 / トウモロコシ=草原・サバンナ / 枝豆=森林・川 / サツマイモ=サバンナ・荒野 / キャベツ=タイガ・山岳 / タマネギ=草原・サバンナ / パプリカ=サバンナ・ジャングル / イチゴ=森林・花の森 (凍った地域は除外)。

## 修正: 野生株が生成されない
- 地形生成(feature_rules)は、草原の地表を覆う「背の低い草」の上を基準にしてしまい、草ブロックに接していない扱いで弾かれていた可能性が高く、ゲーム外で検証もできないため廃止。
- スクリプト生成に変更: プレイヤーの周り半径6チャンクで、まだ調べていないチャンクを1度だけ調べる(1秒に最大6チャンク)。調べたチャンクは16x16チャンクの領域ごとのビット列でワールドに記録。
  探索済みのワールドでも、初めて近づいたチャンクに生える。森では葉・幹の下の土までたどる。凍った地域・海・砂漠・湿地などは除外。
- 生え方はバニラの花畑と同じ方式: 中心のまわりに8〜14回投げて置ける所に生やし、中心ほど密(三角分布・半径約4)、すき間あり。1か所におおむね3〜11株(中央値7)。
