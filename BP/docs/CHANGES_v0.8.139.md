# v0.8.139 工廠ライフル: 一人称の表示と GVC 式の操作

## 一人称で画面が茶色一色になる
- 原因: 一人称モデルが腕の骨を持たず body に直接付き、銃の中心が目の高さ (y≈26) にあった → カメラが銃の中に入っていた。
- GVC の方式を解析して同じ構造に変更: root→body→rightArmA→rightArm(-5,22,0)→gun(pivot -6,-19,-2・Z-180°)。
  銃は腕の骨の先に「銃口が手側・銃床が肩側」でぶら下がる (GVC の AK47 と同じ位置・向き・長さに合わせて配置。工廠ライフルの前=-Z/上=+Y を Y180°・X-90° の2段で GVC の向きへ変換)。
- 腰だめ: GVC の first2 と同じ値 (gun 回転 -1.6/-0.47/0.14・位置 0/-8.6/2)。
- しゃがみ=スコープ: GVC の ads2 と同じ構え (gun 回転 8.7/-62.1/668.7・位置 95.8/-52.5/-16.4)、視野 50 (レールガン 30)。

## 操作 (GVC と同じ)
- 右クリック: 射撃 (しゃがみ中も撃てる)。左クリック: 装填。しゃがみ: スコープ。
- 左クリックは腕振りイベント playerSwingStart で検出 (使用・設置などの振りは除外)。ブロック/敵を叩いたときも装填。
- そのため @minecraft/server を 2.0.0 → 2.7.0 に (Minecraft 1.26.20 以降が必要)。
- 弾切れ時の表示・図鑑の説明を新しい操作に。
