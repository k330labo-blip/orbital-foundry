# v0.8.141 銃の一人称が三人称モデルのままだった
- 原因: 銃のアタッチャブルが format 1.10.0 で、一人称判定 context.is_first_person が効かず、一人称でも三人称モデル・三人称アニメが使われていた (一人称専用の手袋が見えないことから判明)。
  v0.8.139/140 の見た目の変化が無かったのはこのため。
- GVC と同じ書式に: format 1.16.100、identifier を <銃>.player にして item でプレイヤー所持時に適用、判定は c.is_first_person を変数に入れて使う。銃10種すべて。
- v0.8.140 の「横倒し・大きすぎ」の補正(ロール-90°・0.8倍)は三人称モデルを見ての判断だったので取り消し、GVC の AK47 と同じ構え(first2 / ads2)に戻す。
- ショットガン・レールガンの一人称モデルも、ライフルと同じく GVC の骨構造(腕に付いて銃口が手側)へ変換。
