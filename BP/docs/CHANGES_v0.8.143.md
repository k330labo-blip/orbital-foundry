# v0.8.143 銃の一人称: 手に付いた銃を回して構える
- v0.8.142 で一人称専用の部品(fp_*)が出るようになったが、GVC はプレイヤー本体の一人称の腕の構えも書き換えているため、同じ数値では銃口が左上を向いた。
  また三人称の銃を隠す指定 (rightItem の scale 0) は、プレイヤーの手の位置に固定される骨なので効かなかった。
- 方針変更: fp_* を削除し、手に正しく付いている三人称の銃をそのまま使う。一人称のときだけ回して構える。
  観察: 一人称で手に付けたままだと 銃口=画面の上・弾倉=画面の右 → 必要な回転は hand_binding で Z-90°、weapon で X+90° (計算で導出)。
- しゃがみ(スコープ)は視野を狭め、手袋の表示を消す。位置の寄せは向きが合ってから調整。
