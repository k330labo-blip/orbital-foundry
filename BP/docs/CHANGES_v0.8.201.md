# v0.8.201 加工機の製品アイコン表示
- 加工機（粉砕機・洗浄機・高度選鉱機・電気炉・合金炉・プレス機・製線機・組立機・精製機）と原油ポンプの上に、工業コンテナの収納物表示と同じ枠で「いま作っている物」のアイコンを1つ浮かべる。
  - 加工中はそのレシピの製品。待機中でもレシピを指定していれば、その製品を出す。材料で自動選択の待機中は枠ごと消える。
  - 精製機はレシピの代表アイコン（精製燃料）、原油ポンプは稼働中のみ原油。
  - 粉砕機・炉など1ブロックより背の高い機械は、モデルに重ならないよう表示を持ち上げる。名前ラベルも表示枠の上に移した。
- 表示は storage_display を1枠モード（single / product プロパティ）で使い回す。新規モデル machine_product.geo.json。
- アイコン表に、粉砕鉱・未処理鉱石など（247〜261）と、金塊・高密度合金・精密駆動部品・拡張チューブ・蓄電セル（262〜266）を追加。コンテナの収納物表示でも、これらが小包アイコンではなく正しい絵で出るようになった。
