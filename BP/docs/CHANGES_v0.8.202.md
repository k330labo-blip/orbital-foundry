# v0.8.202 高度選鉱機の専用モデル・機械の在庫画面を復活
## 高度選鉱機
- 洗浄機と共用だったモデルをやめ、専用モデル `workshop_ore_beneficiator.geo.json` と専用テクスチャ（ore_beneficiator_*）を新設。
  - 濃紺の装甲本体と金の飾り帯、四隅の発光帯、中央にガラスの浮選槽（液体・泡は半透明）、正面に「×5」画面・棒グラフ・表示灯の操作盤、左に原鉱ホッパー、右に精鉱の搬出ベルト、背面に油圧ピストン、上部にモーターと磁選ドラム。
  - 稼働中は4コマで: 撹拌羽根2段が逆回転、気泡が上昇、モーターのファンと磁選ドラムが回転、ピストンが互い違いに上下、ベルト上を精鉱が流れ、ホッパーに原鉱が落ち、表示灯が順に点き棒グラフが動く。
  - 稼働中は槽・画面・発光帯・表示灯が明るくなり、明るさ6で光る。
  - アイコン（textures/blocks/ore_beneficiator.png）も新しい正面図に。製品表示の高さも新モデルに合わせた。
## 機械の右クリック
- 在庫エンティティ（*_slots）の当たり判定が全状態で無効（1000ブロック上）になっていたため、かまど風の在庫画面が開かなくなっていた。普段は機械と同じ大きさに戻した。
- 右クリック: かまど風の在庫画面（材料・燃料・完成品のスロット）。
- シフト＋右クリック: 詳細設定（生産設定・レシピ・速度上限・在庫の一覧など。機械ごとの従来の設定画面）。シフト＋レンチは従来どおり倍速設定。
- しゃがんでいる人の近くでは当たり判定を縮めてブロックへ通すので、シフト＋右クリックの設定とブロック設置ができる。機械を叩くと3秒間縮めて採掘できるようにした。
- 未研究の機械、レンチを持っている時、軌道便の出る発射台は、在庫画面ではなく従来の画面を開く。
