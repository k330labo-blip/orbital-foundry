# v0.8.203 かまど風の在庫画面が開かない問題の修正
- v0.8.202 では在庫エンティティ (*_slots) の custom_hit_test だけを広げていたが、これは攻撃の当たり判定で、右クリックの対象には使われない。右クリックは collision_box で決まり、これが常に 0×0 だったため画面が開かなかった。
- 「extend」状態で collision_box を 0.98×0.98 に、「retract」状態では 0×0 にする。
- 在庫エンティティの位置をブロックの中段 (+0.45) から床面 (+0.02) に下げ、当たり判定がブロック全体を覆うようにした。既存のエンティティは読み込み時に自動で移動する。
- ツルハシ・斧・シャベルを持っている間も当たり判定を縮め、機械をそのまま掘れるようにした (しゃがみ中と同じ)。
