# v0.8.75 進行・軌道便・ボス記録の修正

v0.8.74のソース確認で見つかった問題を修正。UUID・ブロック/アイテム/研究IDは変更なし。既存ワールドの研究・在庫・機械登録はそのまま引き継ぐ。

## 修正内容
- **石炭発電機クエストのヒント**：「鉄インゴット×8＋かまど」を実際のレシピ「丸石×4＋板材×4（種類自由）＋かまど」に修正。
- **氷小惑星便の使い道**
  - 真空氷：軌道便の推進剤。ロケット燃料12個が足りないとき、真空氷4個で1便を出せる（燃料を優先）。電力不足のときは何も消費しない。
  - イリジウム：軌道ブレード強化の素材。Lv1～5でイリジウム2/4/6/8/10個（強化コア2/4/6/9/12個と併用）。上限Lv5は変更なし。
  - ゲーム内ガイドに「軌道便と装備強化」ページを追加。
- **ロケット・軌道便の時間**：実時刻（Date.now）で計っていたため、ワールドを閉じている間も飛行時間が進んでいた。ワールド内時計 `of:game_ms`（ワールド稼働中だけ1秒ごとに進む）で計るよう変更。旧版で飛行中の便は、読み出し時に残り時間を保ったまま移行する（`clock:"game"` で判定）。
- **ボス記録の残留**：オーバーシアが `/kill` などで消えると「活動中」の記録が残り、再召喚も中止もできなくなっていた。
  - スクリプトのHP判定を通らずに死亡した場合は記録を消す（報酬なし）。
  - 召喚・中止のとき、召喚地点のチャンクが読み込まれていて本体が見つからなければ、記録を消して起動核を返却。未読込の場合は従来どおり記録を残す。
  - 記録と結びつかないオーバーシアが読み込まれたら除去する。
- **樹脂**：粉砕機でオーク以外の原木（トウヒ・シラカバ・ジャングル・アカシア・ダークオーク・マングローブ・サクラ・ペールオーク）2個からも作れる。生産ツリーは代表の1ノードのまま（31ノード）で、詳細に対応原木を表示。
- **ドキュメント**：`FLUIDS_v0.8.72.md` に残っていた旧仕様の原子炉数値（800℃稼働・1800℃メルトダウン）を現行仕様（1万℃・2万℃）に修正。
