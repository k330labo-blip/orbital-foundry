# v0.8.77 デバッグ設備・組立機の見た目・エフェクト修正

- **無限発電機（クリエイティブ）** `orbital_foundry:creative_generator`：ケーブルでつないだ機械に、常に満タン（10億SE）の電力を供給。発電機として扱うので既存の電力網にそのまま入る。
- **無限液体源（クリエイティブ）** `orbital_foundry:creative_fluid_source`：水・原油・精製燃料を常に満タンに保ち、隣の配管へ送る。配管の液種設定に合わせて流れる。
- どちらもクリエイティブインベントリの「アイテム」欄にあり、レシピなし。サバイバルで置こうとすると取り消す。
- **組立機**：側面と背面が空いた枠だけの形で、向こうが透けて見えていた。側面・背面・屋根を鋼板で閉じ、正面は作業窓として残した。プレス・歯車の動きは見える。
- **チャンクデストロイヤー**：電力不足などで止まっていても破片が飛ぶことがあった。破片・カッター回転・ドリル頭の回転・状態灯を「直近に実際にセルを掘った」ときだけにした。
- **固定ドリル**：電力不足・満杯・枯渇になっても、巡回処理が回ってくるまで削りかすが出続けることがあった。約1秒ごとに状態を確認して止める。
- 他の機械（粉砕機・石炭発電機・工房機械の蒸気）は、電力を払って加工中・燃焼中のときだけエフェクトを出すことをコードで確認。
