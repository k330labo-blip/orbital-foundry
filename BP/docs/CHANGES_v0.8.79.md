# v0.8.79 工業コンテナの複数品目化・収納物表示・格子画面

- 工業コンテナは複数品目を保管できる（容量は全品目の合計: Mk I 4,096個 / Mk II 32,768個）。物流の搬出は品目ごとのスロット、搬入は合計の空きまで。v0.8.76〜78 の1品目形式の保存データは読み出し時に移行する。
- コンテナの上に、真鍮枠の看板がゆっくり回りながら浮かび、多い順に4品目のアイコンを表示（`orbital_foundry:storage_display`）。アイコンはベルト荷物と同じ一覧に、石材・ラピスラズリ・レッドストーンなどを足したもの。
- コンテナの画面を、工業MODの倉庫端末（AE2・Storage Drawers など）に倣った格子表示に変更。上段に保管数・品目数・空き・残量バー・搬入出の設定、下に品目のアイコンと正確な個数を3列で並べる。品目を選ぶと 1個／1スタック／入る分 を取り出せる。持ち物の手持ち・全部を預けるボタン付き。（RP `server_form.json` の `of_grid_panel`。タイトル先頭の印 §s§t で切り替え）
- 「隣の倉庫へ送る（旧型からの移し替え用）」は分かりにくく、ベルト・機械で足りるため削除。
