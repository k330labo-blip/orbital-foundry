# v0.8.81

- 電力: ケーブルで発電機とつながっていない機械は電力を使えない（全機械）。以前は、ケーブルのない機械がワールド内の「どこかのケーブルにつながった発電機」と旧版の共有電力から引けていた。旧版の共有電力は、ケーブルでつながった機械だけが使う。採取契約などプレイヤー操作の支払いは従来どおり。
- 掘削ガントリーの脚: 東西を取り違えていて、高い地面に長い脚・低い地面に短い脚が付いていた。エンティティのモデルはワールドと同じ向き（X+＝東）として四隅を対応させ直した。稼働中のジョブも組み直し時に測り直す。
- 工業コンテナの画面: 格子画面（v0.8.79）は実機でボタンが空白・枠が重なる・押すと右クリックが効かなくなる不具合があったため廃止し、他の機械と同じ一覧画面に戻した。品目ボタンにはアイコンと個数が出る。残量バーの ■□ が文字化けしたため [|||....] 表記に変更（チャンクデストロイヤーも同様）。
