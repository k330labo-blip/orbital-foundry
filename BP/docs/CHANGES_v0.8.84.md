# v0.8.84 チャンクデストロイヤーのネザー・エンド対応

- オーバーワールド専用の制限を外し、ネザー・エンドでも測量・掘削できる。
- 廃棄フィルターに「ネザー系」（ネザーラック・ナイリウム・ソウルサンド・ソウルソイル・玄武岩・ブラックストーン・マグマ・ウォートブロック）と「エンド系」（エンドストーン）を追加。
- 鉱石: ネザークォーツ鉱石→クォーツ、ネザー金鉱石→金塊2〜6、ブラックストーン（金入り）→金塊2〜5、古代の残骸→古代の残骸（幸運なし）。
- 撤去のみ: クリムゾン・ワープドの根と菌・ネザースプラウト・つる・炎・魂の炎・コーラスプラント／フラワー。
- 岩盤: ワールドの底5層（オーバーワールド Y-64〜-60、ネザー Y0〜4）に当たった列だけを終端にする。ネザーの天井の岩盤は残して下へ進む。エンドは底（Y0）まで掘って完了。
- 開始の高さの推奨値: ネザー・エンドでは本体の高さ+16から下の地面を探す（天井の岩盤を地面と誤認しない）。上限はワールドの高さに合わせる。
- テスト: ネザー（天井・底の岩盤、溶岩、各鉱石）とエンドでの掘削を追加。
