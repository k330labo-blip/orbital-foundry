# v0.8.87 掘削範囲の選び方（正面の扇形＋掘削マーカー）

他MODの方式（BuildCraft のクオーリーは正面＋ランドマーク、Extra Utilities の Ender Quarry は柵／マーカー、Mekanism の Digital Miner は本体中心の半径）を参考に、A（正面の扇形）＋C（目印）にした。

- 正面の扇形: 本体の正面の向き（設置時の向き、`minecraft:cardinal_direction`）から、正面と左右の斜めの3列。Mk I は1列先の3チャンク、Mk II は2列先まで6チャンク、Mk III は3列先まで9チャンク（掘削中1＋予約8に足りる）。周囲8チャンクから選ぶ方式は廃止。
- 掘削マーカー `orbital_foundry:quarry_marker`: 置いたチャンクが掘る候補になる（同じディメンションで8チャンク以内、本体のチャンクは除く）。上に黄黒の光の柱。大規模掘削の研究後、設備製作で 鋼板×1・レッドストーン×2・黄色の染料×1 → 4個。撤去すると候補から外れる。最大64個まで記録。
- 分かりやすさ: 測量画面と本体の画面に、本体から見た文字の地図を表示（掘＝掘削中、1〜8＝予約順、計＝計画中、他＝別の掘削機、・＝空き、機＝本体）。予約済みのチャンクは青緑と黒の線、掘削中は黄黒の線。候補ボタンには「1列先・正面」「2列先・東寄り」などの位置と、掘削中／予約済み／他機担当中を表示。
