# v0.8.88 掘削マーカーの登録制・距離制限（マルチプレイ対策）

- 掘削マーカーは置いた人を記録する。チャンクデストロイヤーも設置した人を持ち主として記録する（旧版の機械は、最初に画面を開いた人）。
- マーカーは置くだけでは候補にならない。本体の画面「掘削マーカーを登録」で、持ち主が自分で置いたマーカーだけを登録・解除できる。候補の計算でも、持ち主以外が置いたマーカーは除外する。
- 効く距離を本体のチャンクから Mk I 2・Mk II 3・Mk III 4チャンク以内に短縮（以前は8チャンク）。
- チャンクデストロイヤーを撤去すると、持ち主の記録とマーカーの登録を解除する。
