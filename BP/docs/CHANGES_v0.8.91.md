# v0.8.91 敵の装甲（他アドオンとの併用向け）

- スクラッパー・ジャマーの本当の体力を1000にし、HP（18／24）はスクリプトが `of:hp` で管理する。どんな大きな一撃でも、判定の前に倒れることはない。HP が0になったら kill する。
- 通す割合（`defense.js` の `armorMultiplier`、`DEFENSE.armor.otherAddon` で調整）:
  - 100%: このアドオンの機関砲塔。バニラの攻撃（プレイヤー・`minecraft:` のモブの近接、`minecraft:` の飛び道具（矢・トライデントなど）、炎・溶岩・落下・溺水・ポーション・TNT など）。
  - 15%: 他のアドオン由来の攻撃。`minecraft:` 以外の弾エンティティ、`minecraft:` 以外のモブ・爆発、弾なしの「射撃」ダメージ（スクリプトの銃）、独自の原因。
- 弾かれたときは小さな灰色の火花を出す。
- 制限: 他アドオンの銃が「プレイヤーの近接攻撃」と同じ原因（entityAttack・攻撃者=プレイヤー・弾なし）でダメージを入れる場合は、剣と区別できず100%通る。併用するアドオンの弾IDやダメージの入れ方が分かれば、個別に判定を足せる。
