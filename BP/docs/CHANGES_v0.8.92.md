# v0.8.92 GVC（ゲリラ）アドオンとの併用

GVC Bedrock Addon（KarZex/gvcAddon、V6.1）のソースを確認した。GVC の銃は、弾（`fire:` などの弾エンティティ）の命中を `projectileHitEntity` で受け、スクリプトから `applyDamage(ダメージ, { cause: 銃ごとの種類（entityAttack など）, damagingEntity: 撃った人 })` で入れる。ダメージの記録には弾が残らず「プレイヤーの攻撃」に見えるため、v0.8.91 の判定では剣と区別できなかった。

- 敵に `minecraft:` 以外の弾が当たった瞬間を記録し（`of:addon_hit`）、その前後2tick以内に入ったダメージは他アドオン由来として15%だけ通す。徹甲弾・炸裂弾の爆発（同じ処理内で起きる）も同様。
- 攻撃者が `minecraft:` 以外の乗り物（GVC の戦車 `vehicle:` など）に乗っていれば他アドオン由来（体当たり・主砲）。馬などバニラの乗り物は対象外。
- バニラの剣・弓・トライデント・TNT・炎・溶岩などと、このアドオンの機関砲塔は従来どおり100%。
- GVC 側にも独自の弾防御（敵のプロパティ `zex:anti_bullet`）があるが、GVC専用で二重に減るため使わず、どのアドオンでも効くこの方式にした。
