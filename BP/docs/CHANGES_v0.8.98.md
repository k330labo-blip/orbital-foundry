## 敵AIが端末へ来ない不具合
- 原因1: 防衛目標エンティティ(defense_objective)が is_summonable:false で、スクリプトから出現できず AI の追跡目標が存在しなかった → true に。
- 原因2: 出現距離36〜48に対し、端末ブロック探索(move_to_block)が40ブロック・目標探索が48 → 64に拡大、follow_range も64。
- 原因3: 詰まり時の再配置が「出現点[0]」(最大48ブロック先・別方角)へ戻していた → 4秒停滞で端末方向へ押し出し＋ジャンプ、12秒で端末寄り(道のり30〜75%)の地面へワープ。

## 敵の行動パターン
- スクラッパー: 中距離で1秒溜め(カチッ＋砂煙)→直線突進。被弾時30%で横ステップ。
- ジャマー: 被弾時40%で3ブロックの短距離ブリンク（妨害の溜め中は逃げない＝倒すチャンス）。
- ジャマー→砲塔の電撃ビーム: 予告中は細い紫の点線、妨害中はギザギザの稲妻（0.25秒ごと再描画）。妨害された砲塔は放電＋パチパチ音。

## 演出追加
- 全砲塔: 砲口の煙。機関砲・ショットガン: 薬莢が跳ねて地面でバウンド。レールガン: 砲口の衝撃リング・放電、着弾の青白い閃光。
- 敵出現: 紫の光柱。撃破: 黒煙＋爆発音。端末被弾: 赤い衝撃波リング。

## 鋼の防具（新規）
- 鋼のヘルメット/チェストプレート/レギンス/ブーツ。防御力はダイヤより少し上の 4/9/7/3（合計23、ダイヤは20。防具強度が無い分を補う）、耐久はダイヤの約1.3倍 480/700/650/560。
- 作業台レシピ（鋼インゴット。チェストは中央に鋼板）。金床で鋼インゴット修理（1個で25%）。エンチャント適性12（ダイヤ10より付きやすい）。
- 装着時の見た目: 鋼板＋リベット、オレンジの警告ライン、ヘルメットに水色のバイザー。

## 砲塔が「?」ブロックになる問題（暫定対策）
- 8方向に回る砲身の斜め向きが中心から最大13.8px（レールガン）まではみ出していた。動作実績のあるブロック（電力ケーブル 10.2px）以内に収まるよう、全砲塔の旋回部を半径9.8px以内にクリップ。
- レールガンは砲身が短くなったため、マズル位置(muzzleLength)を0.85→0.58に調整。
