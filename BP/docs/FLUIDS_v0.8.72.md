# v0.8.72 液体・発電アップデート

## 遊び方
1. 電子工学を研究し、研究画面の設備製作で揚水ポンプ・液体パイプ・タンクを製作。
2. 揚水ポンプに水源を隣接させ、送電ケーブルで給電。水は1000 mB/秒、10 SE/秒。
3. パイプを右クリックして輸送する液体（水・原油・精製燃料）を選択。上下を含む6面接続。同じ液体設定の配管を使う。
4. 原油ポンプへ水1000 mBと石炭1個、250 SEを供給すると4秒ごとに原油500 mB。石炭はベルト・チェストから自動搬入できる。
5. 精製機へ原油パイプを接続。原油1000 mB→精製燃料600 mB＋樹脂1、8秒・1000 SE。精製燃料を取り出す別の配管は精製燃料に設定する。
6. 洗浄機は水1000 mB、青研究パックは精製燃料500 mBを使用。水バケツや空バケツは不要。
7. タンク64000 mB、各機械の液体バッファ8000 mB/液種。残量は右クリック画面かレンチ設定で確認。液体は保存される。タンク内の別液種が残っている間は切替不可。
8. 旧版の原油・精製燃料アイテムは、液体系統のある機械在庫に入れると1個1000 mBとして変換。新レシピからは出ず、クリエ一覧も非表示。

## 電力
- 石油火力：原油400 mB/秒または精製燃料200 mB/秒を消費し2000 SE/秒。精製燃料を優先。内蔵蓄電100000 SE。満杯なら燃料を消費しない。
- 原子炉（v0.8.73で数値変更。現行仕様は REACTOR_v0.8.73.md / REACTOR_v0.8.74.md）：3×3×3の構造が完成している場合だけ稼働。外部電力2000 SE/秒で10000℃まで約100秒（200000 SE）昇温。自身の蓄電だけでは昇温しない。
- 稼働中：ウラン燃料棒1本1200秒、冷却水500 mB/秒、12000 SE/秒、内蔵蓄電1000000 SE。使用済み燃料棒を完成品枠に排出。冷却水がある間は最大15000℃。
- 原子炉の外壁を右クリックすると炉心の状態画面を開き、温度・水・燃料時間・運転停止を操作。
- 停止後も高温の炉心には冷却水が必要。冷却水切れや炉構造の破損で過熱し、20000℃でメルトダウン。
- メルトダウンはネイティブ爆発半径50、地形破壊と出火あり。爆心から半径50は30分間、2秒ごとに2ダメージ。汚染の残り時間と位置は保存され、ワールド停止中は進まない。
- 爆発は一度だけ。原子炉登録と蓄電を破棄。実際の地形破壊範囲はブロックの爆発耐性に影響される。
- 上位加工費：青パック1200、制御ユニット3000、紫パック5000、機体区画18000、誘導装置22000 SE/回。石炭発電の大量並列は可能だが石油・原子力への移行が効率的。

## ウラン
新規生成のオーバーワールド地下Y=-56～0、上面が空気に接する洞窟鉱床。固定ドリルで採掘、埋蔵量800～2400。
原子力研究後、電気炉で原鉱1→ウラン1（12秒・2000 SE）。組立機でウラン4＋鋼板2＋耐熱合金1→燃料棒1（15秒・4000 SE）。採取契約でもウラン原鉱を入手可能。
