# v0.8.74 原子炉構造・外壁GUI

3×3×3の中央に実在する登録済み原子炉があり、外壁26個が指定の材質で完成している場合だけ、その外壁を右クリックすると原子炉GUIを開きます。村のガラス・要塞の石レンガ・原子炉から離れたブロック・別ディメンションのブロックには反応しません。炉本体を撤去した直後の古い登録だけでは反応しないよう補強しました。

上段・下段：中央ガラス、周囲8個は石レンガ。
中段：中央原子炉、四隅石レンガ、残り4か所ガラス。

外壁が1個でも欠ける・材質が違う場合、昇温・発電・燃料消費を開始しません。既に高温の炉も新たな発電は停止します。ただし既存仕様どおり、高温の炉の外壁破壊は冷却不能による過熱を招きます。未読み込みの外壁は破壊と区別して一時停止します。

外壁クリックの前後イベントが重複しても画面を二重に開かないよう、同じ原子炉の操作として統一しました。

検証：外壁26か所それぞれのGUI、全26か所の欠損・誤配置、普通の石レンガとガラス、炉本体撤去後の残存登録、ディメンション違いをテスト。各外壁を1個ずつ除いた場合に、冷間起動・高温発電・ウラン消費・起動電力消費が止まることを確認。Minecraft実機の画面操作は未確認。
