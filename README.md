# 軌道工廠 Orbital Foundry

Minecraft統合版（Bedrock）の工業化アドオン。掘削→加工→搬送→研究→軌道産業まで進む、スチームパンク風の大型工業パックです。

**現在のバージョン: v0.8.326**

## ダウンロード

- このリポジトリ内の `OrbitalFoundry_v0.8.326.mcaddon` をダウンロードしてください（Releases にも同じファイルを置いています）。

## 導入方法

1. `.mcaddon` ファイルを開くと Minecraft が起動し、ビヘイビアパックとリソースパックが自動でインポートされます。
2. ワールドの作成／編集画面で、ビヘイビアパックとリソースパックの両方に「軌道工廠」を適用してください。
3. 機械のメニューは「しゃがみ＋右クリック」で開きます。詳しい攻略は攻略Wikiをご覧ください。
